\vspace{5pt}
{\large\bfseries\color{navy}Resumo executivo}\\[-1pt]
O fIAq é um portal do CIC/UnB com FAQ por tema e assistente virtual com IA. A aplicação roda em \textbf{Nuxt 4 + Vue 3 + Nitro}, dentro de \texttt{fiaq-app/}, com frontend, APIs server-side, streaming de chat e registro de métricas anônimas no Supabase. A entrega está publicada no projeto \textbf{fIAq} em \href{https://fiaq-app.vercel.app}{\textbf{https://fiaq-app.vercel.app}}, no caminho gratuito \textbf{Vercel Hobby + Supabase Free + OpenRouter}.
